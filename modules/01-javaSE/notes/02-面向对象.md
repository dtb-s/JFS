## 1. 从面向过程到面向对象

**面向过程**：把任务拆成一步步操作，程序 = 数据结构 + 算法。
**面向对象**：把现实世界抽象成"对象"，每个对象有属性（数据）和方法（行为）。

做菜的例子：

- 面向过程：洗菜 → 切菜 → 炒菜 → 装盘
- 面向对象：厨师对象.炒菜(食材对象)；食材对象有自己的名字、重量

程序变大后，面向过程的代码会越来越乱（数据和操作分离，改一处牵全身）。面向对象把"数据"和"操作数据的方法"绑在一起，更贴近人的思维方式，也更容易维护和复用。

**类和对象：**

- 类（class）= 图纸 / 模板：描述"这类东西长什么样、会干什么"
- 对象（object）= 按图纸造出来的具体实例

```java
// 类：图纸
class Student {
    String name;   // 属性
    int age;

    void introduce() {   // 方法
        System.out.println("我叫" + name + "，今年" + age + "岁");
    }
}

// 对象：实例
Student s = new Student();
s.name = "小明";
s.age = 18;
s.introduce();
```

**类加载（了解即可）：** 当你第一次用到某个类（比如 `new Student()`）时，JVM 会把这个类的 `.class` 字节码加载进内存，这个过程叫**类加载**。每个类只会被加载一次。加载的细节（类加载器、双亲委派）到"反射与注解"课再深入，现在知道有这个过程就行。

## 2. new 一个对象时发生了什么

```java
Student s = new Student();
```

这一行做了三件事：

1. 在**堆内存**中给对象分配空间
2. 执行**构造方法**（完成初始化）
3. 把对象的内存地址返回，赋给引用变量 s

**基本类型 vs 引用类型（重点）：**

```java
int a = 10;        // a 直接存值 10
Student s = ...;   // s 存的是对象的"地址"，不是对象本身
```

- 基本类型变量 = 值本身
- 引用类型变量 = 指向对象的地址（可以理解为"遥控器"，对象是"电视机"）

**对象属性的默认值：** `int` 是 0，`double` 是 0.0，`boolean` 是 false，`char` 是 '\u0000'，引用类型是 null。不赋值直接用不会报错（**局部变量相反**：不赋值就使用会编译错误）。

## 3. 构造方法

构造方法是专门用来"初始化对象"的方法：

```java
class Student {
    String name;
    int age;

    // 无参构造
    Student() {
        name = "未命名";
    }

    // 有参构造（重载：参数列表不同）
    Student(String n, int a) {
        name = n;
        age = a;
    }
}
```

**规则（背下来）：**

1. 方法名必须和类名**完全一致**
2. **没有返回类型**，连 void 都不能写
3. 只能通过 `new` 调用
4. 不写任何构造方法时，编译器会提供一个默认无参构造；**只要写了任何一个构造方法，默认构造就没了**
5. 构造方法可以重载（参数列表不同）

**this 关键字：**

```java
Student(String name, int age) {
    this.name = name;   // 左边是成员变量，右边是参数（局部变量）
    this.age = age;
}

Student() {
    this("未命名", 0);   // this(...) 调用另一个构造方法，必须写在第一行
}
```

- `this.属性`：明确表示"当前对象的属性"，解决参数和属性重名
- `this(...)`：在构造方法里调用另一个构造方法，必须写在第一行

## 4. 封装

封装 = 把属性藏起来（`private`），对外提供受控的访问方法（getter/setter）。

**为什么要封装？** 不封装的话，谁都能把年龄改成负数：

```java
// 不封装
s.age = -100;   // 数据被搞坏了

// 封装后
class Student {
    private int age;

    public void setAge(int age) {
        if (age < 0 || age > 150) {
            System.out.println("年龄不合法：" + age);
            return;   // 拒绝修改
        }
        this.age = age;
    }

    public int getAge() {
        return age;
    }
}
```

**4 种访问修饰符（核心考点）：**

| 修饰符 | 同类 | 同包 | 子类（不同包） | 任意类 |
| --- | --- | --- | --- | --- |
| `private` | ✓ | ✗ | ✗ | ✗ |
| 默认（不写） | ✓ | ✓ | ✗ | ✗ |
| `protected` | ✓ | ✓ | ✓ | ✗ |
| `public` | ✓ | ✓ | ✓ | ✓ |

**小技巧：** 用 IDEA 时，写完 private 属性后右键 → Generate → Getter and Setter 可以自动生成，但学习阶段建议手写几遍。

## 5. 继承

继承 = 子类复用父类的属性和方法，并在其基础上扩展。

```java
class Animal {
    String name;

    Animal(String name) {
        this.name = name;
    }

    void speak() {
        System.out.println(name + "发出声音");
    }
}

class Dog extends Animal {
    Dog(String name) {
        super(name);   // 调用父类构造方法，必须写在第一行
    }

    @Override
    void speak() {
        System.out.println(name + "汪汪叫");
    }

    void fetch() {   // 子类新增方法
        System.out.println(name + "叼回了球");
    }
}
```

**关键规则：**

1. Java 是**单继承**：一个类只能有一个父类（但可以多层继承）
2. 子类继承父类的非私有成员；`private` 成员、构造方法不继承
3. 创建子类对象时，**先执行父类构造，再执行子类构造**
4. `super(...)` 调用父类构造，必须写在子类构造第一行；子类构造里没写 `super(...)`，编译器默认调用父类**无参构造**（父类没有无参构造就会编译错误）
5. `@Override` 是注解，表示"我要重写父类方法"。写上它之后，如果方法签名写错了，编译器会立刻报错，强烈建议每次都写

**重写（Override）的规则：**

- 方法签名（方法名 + 参数列表）必须相同
- 返回类型：基本类型必须相同；引用类型可以返回父类返回类型的子类（协变返回）
- 访问权限：不能比父类更小（`public` 不能改成 `private`）
- 静态方法、构造方法、private 方法不能被重写

**重载（Overload）vs 重写（Override）—— 必考区别：**

| 对比 | 重载 Overload | 重写 Override |
| --- | --- | --- |
| 位置 | 同一个类中 | 父子类之间 |
| 方法名 | 相同 | 相同 |
| 参数列表 | **必须不同** | 必须相同 |
| 返回类型 | 无所谓 | 相同或父类返回类型的子类 |
| 访问权限 | 无所谓 | 不能更小 |
| 决定时机 | 编译期（看参数） | 运行期（看对象） |

**Object 类：** 所有类都直接或间接继承 `Object`（不用写 extends）。它有几个重要方法：`toString()`、`equals()`、`hashCode()`。本课先知道存在，"核心 API"课详细讲。

## 6. 多态

多态 = **同一个方法调用，不同对象表现出不同行为**。

**三个条件：**

1. 有继承（或实现接口）
2. 子类重写了父类方法
3. 父类引用指向子类对象

```java
Animal a1 = new Dog("旺财");   // 向上转型：父类引用 指向 子类对象
Animal a2 = new Cat("咪咪");

a1.speak();   // 运行结果：旺财汪汪叫（动态绑定：看对象，不看引用类型）
a2.speak();   // 运行结果：咪咪喵喵叫
```

**向上转型**：把子类对象当父类用。好处是代码可以统一处理：

```java
void makeItSpeak(Animal a) {   // 不管传 Dog 还是 Cat 都能处理
    a.speak();
}
```

向上转型后**只能用父类有的方法**（不能 `a1.fetch()`，因为 Animal 里没有 fetch）。

**instanceof 和向下转型：**

```java
Animal a = new Dog("旺财");
if (a instanceof Dog) {        // 先判断，再转型，安全
    Dog d = (Dog) a;           // 向下转型：父类引用 转回 子类引用
    d.fetch();                 // 现在能调用子类特有方法了
}
```

```java
// 不判断直接转型会抛异常
Cat c = (Cat) a;   // 运行时错误：ClassCastException，a 实际是 Dog
```

**多态的实际意义：** 面向"父类/接口"编程，而不是面向具体类编程。新增一种动物时不用改 `makeItSpeak` 方法——这符合**开闭原则**（对扩展开放，对修改关闭）。这也是后面 Spring 框架一切设计的基石。

## 7. static 关键字

static = 属于"类"的成员，不属于任何对象，**所有对象共享一份**。

```java
class Counter {
    static int count = 0;   // 静态变量：类级别

    Counter() {
        count++;            // 每 new 一次，count + 1
    }

    static void show() {    // 静态方法：类级别
        System.out.println("已创建 " + count + " 个对象");
    }
}

Counter c1 = new Counter();
Counter c2 = new Counter();
Counter.show();   // 已创建 2 个对象（推荐用类名调用）
```

**规则：**

1. 静态成员用 `类名.成员` 访问（也可以用对象访问，但不推荐）
2. **静态方法里不能直接访问实例成员**（没有 this，不知道是哪个对象）
3. 实例方法可以访问静态成员
4. 静态代码块：类加载时执行一次

```java
class Config {
    static String version;

    static {                    // 静态代码块：类加载时执行，且只执行一次
        version = "v1.0.0";
        System.out.println("加载配置");
    }
}
```

**什么时候用 static：** 与对象状态无关的工具方法（如 `Math.max`）、全局常量、计数器。

## 8. final 关键字（深化）

| 修饰 | 效果 |
| --- | --- |
| final 变量 | 只能赋值一次（常量） |
| final 方法 | 不能被子类重写 |
| final 类 | 不能被继承（如 String） |

```java
final class Util { }          // 不能被继承
class A {
    final void run() { }      // 子类不能重写 run
}
final int MAX = 10;           // 常量
```

## 9. 抽象类

**抽象类 = 不完整的类**，用来当"模板"，不能 new，只能被继承。

```java
abstract class Shape {
    String name;

    Shape(String name) {
        this.name = name;
    }

    abstract double area();       // 抽象方法：只有声明，没有实现

    void describe() {             // 普通方法：子类直接继承
        System.out.println("这是一个" + name);
    }
}
```

**规则：**

1. 抽象方法必须在抽象类里（有抽象方法的类必须声明为 abstract）
2. 抽象类**不能 new**（它不完整，比如没有面积公式）
3. 子类必须实现所有抽象方法，否则子类也要声明为 abstract
4. 抽象类可以有普通方法、属性、构造方法（构造方法给子类的 super 用）
5. 抽象方法没有方法体，以分号结尾：`abstract double area();`

**意义：** 强制子类"必须会做什么"，同时公共逻辑（describe）可以复用。

## 10. 接口

**接口 = 一份契约（合同）**：只规定"能做什么"，不规定"怎么做"。

```java
interface Drawable {
    void draw();   // 接口方法默认是 public abstract，修饰符可以省略
}

class Circle extends Shape implements Drawable {
    double radius;

    Circle(double radius) {
        super("圆形");
        this.radius = radius;
    }

    @Override
    double area() {
        return Math.PI * radius * radius;
    }

    @Override
    public void draw() {
        System.out.println("画一个圆");
    }
}
```

**规则（背下来）：**

1. `implements` 实现接口，**一个类可以实现多个接口**（弥补单继承）
2. 接口里的方法默认 `public abstract`（修饰符可以省略）
3. 接口里的变量默认 `public static final`（常量）
4. 实现类必须实现接口的所有抽象方法
5. Java 8+ 支持 `default` 方法：有默认实现，实现类可以不重写

```java
interface Playable {
    void play();

    default void pause() {          // 默认方法：可以有实现
        System.out.println("默认暂停实现");
    }
}
```

**抽象类 vs 接口（必考对比）：**

| 对比 | 抽象类 | 接口 |
| --- | --- | --- |
| 关键字 | abstract class | interface |
| 继承/实现 | 单继承 | 多实现 |
| 构造方法 | 有 | 没有 |
| 成员变量 | 任意 | 只能是 public static final 常量 |
| 普通方法 | 可以有 | Java 8 前没有，现在有 default/static 方法 |
| 语义 | "是什么"（is-a） | "能做什么"（can-do） |

**怎么选：** 想复用代码、描述本质 → 抽象类；只定规范、想多实现 → 接口。

## 11. 内部类（了解即可）

定义在类内部的类。最常用的是**匿名内部类**（Lambda 的基础）：

```java
// 匿名内部类：没有名字的类，直接 new 接口并实现
Runnable r = new Runnable() {
    @Override
    public void run() {
        System.out.println("跑起来");
    }
};
```

本课只需知道：内部类可以访问外部类的成员；匿名内部类常用于"一次性实现接口/抽象类"。到"多线程与并发"课会再见到它，然后被 Lambda 表达式替代。

## 12. 关键字总结

| 关键字 | 作用 | 本课关键点 |
| --- | --- | --- |
| `new` | 创建对象 | 分配堆内存 + 执行构造 |
| `this` | 当前对象 | 区分成员/局部变量；this() 链式构造 |
| `super` | 父类引用 | super() 调父类构造（第一行）；super.成员 |
| `extends` | 继承类 | 单继承 |
| `implements` | 实现接口 | 多实现 |
| `abstract` | 抽象类/方法 | 不能 new，子类必须实现 |
| `interface` | 接口 | 契约；方法默认 public abstract |
| `static` | 类级成员 | 共享；静态方法不能访问实例成员 |
| `final` | 不可变 | 变量/方法/类三种用途 |
| `instanceof` | 类型判断 | 向下转型前必用 |
| `@Override` | 重写标记 | 签名写错编译器立即报错 |
