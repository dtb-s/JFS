## 2. JUnit 5 快速上手

命令行阶段用官方独立 jar（不用 Maven）：

```powershell
cd modules\01-javaSE\lesson11
New-Item -ItemType Directory -Force lib | Out-Null
Invoke-WebRequest -Uri "https://repo1.maven.org/maven2/org/junit/platform/junit-platform-console-standalone/1.12.2/junit-platform-console-standalone-1.12.2.jar" -OutFile "lib\junit-platform-console-standalone.jar"
```

```java
class CalculatorTest {

    Calculator calc;

    @BeforeEach
    void setUp() {                       // 每个测试方法执行前运行
        calc = new Calculator();
    }

    @Test
    void addShouldReturnSum() {          // 方法名描述"行为"
        assertEquals(5, calc.add(2, 3)); // 断言：期望值在前，实际值在后
    }
}
```

常用断言：

```java
assertEquals(expected, actual);
assertNotEquals(1, result);
assertTrue(cond); assertFalse(cond);
assertNull(obj); assertNotNull(obj);
assertThrows(ArithmeticException.class, () -> calc.divide(1, 0));
```

失败信息 `expected: <5> but was: <4>` 直接给出期望与实际，很好定位。

命令行运行：

```powershell
javac -encoding UTF-8 -cp "lib\junit-platform-console-standalone.jar" -d out Calculator.java CalculatorTest.java
java -jar lib\junit-platform-console-standalone.jar --class-path out --scan-class-path
```

## 3. IDEA 断点调试

| 操作 | 快捷键 | 作用 |
| --- | --- | --- |
| 打断点 | 点行号左侧 | 运行到此处暂停 |
| 启动调试 | Shift + F9 | 以调试模式运行 |
| Step Over | F8 | 执行当前行，不进入方法 |
| Step Into | F7 | 进入方法内部 |
| Step Out | Shift + F8 | 跳出当前方法 |
| Resume | F9 | 运行到下一个断点 |
| 停止 | Ctrl + F2 | 结束调试 |

- **条件断点**：右键断点输入条件（如 `i == 100`），循环只在满足时停下
- **调试窗口**：Variables 看变量值、Watches 监控表达式、`Alt + F8` 临时执行表达式或改变量值

**调试思路**：确认症状 → 在可疑处打断点 → 单步观察变量在哪一步开始不对 → 缩小范围定位根因 → 修复后重跑相关测试。

**技巧**：二分定位（先在中间打断点）；堆栈从下往上看调用链；不要猜，要看。
