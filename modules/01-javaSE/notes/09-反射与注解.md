## 1. 什么是反射

**反射（Reflection）= 程序在运行期动态获取类的信息（构造/方法/字段/注解），并动态操作它们。**

正常开发：编译期就确定调用谁：

```java
Student s = new Student();
s.study();
```

反射：运行期才知道类名和方法名（比如从配置文件读取），照样能调用：

```java
Class<?> clazz = Class.forName("lesson09.Student");   // 字符串指定类
Object obj = clazz.getConstructor().newInstance();    // 反射创建对象
clazz.getMethod("study").invoke(obj);                 // 反射调用方法
```

**为什么要反射：** 框架（Spring、MyBatis、JUnit）在写代码时根本不知道你会定义什么类，必须等运行期拿到你的类，再动态创建和调用——这就是反射。**框架 = 反射 + 注解。**

## 2. 获取 Class 对象的三种方式

```java
// 方式一：类名.class（编译期就知道类）
Class<Student> c1 = Student.class;

// 方式二：对象.getClass()（有对象时）
Student s = new Student();
Class<? extends Student> c2 = s.getClass();

// 方式三：Class.forName("全限定名")（最灵活，字符串驱动，最常用）
Class<?> c3 = Class.forName("lesson09.Student");
```

三种方式拿到的是**同一个** Class 对象（类只加载一次）：

```java
System.out.println(c1 == c3);   // true
```

## 3. 反射核心操作

### 3.1 创建对象

```java
Class<?> clazz = Class.forName("lesson09.Student");

// 调用无参构造
Object obj = clazz.getConstructor().newInstance();

// 调用有参构造（String, int）
Constructor<?> ctor = clazz.getConstructor(String.class, int.class);
Object obj2 = ctor.newInstance("小明", 18);
```

### 3.2 调用方法

```java
// getMethod：拿 public 方法（含继承的）
Method m = clazz.getMethod("study", String.class);   // 方法名 + 参数类型
m.invoke(obj, "数学");                                // 传对象 + 实参

// getDeclaredMethod：拿本类声明的所有方法（含 private）
Method privateM = clazz.getDeclaredMethod("secret");
privateM.setAccessible(true);                        // 解除 private 限制
privateM.invoke(obj);
```

### 3.3 访问字段

```java
Field f = clazz.getDeclaredField("name");   // 本类声明的字段
f.setAccessible(true);                       // private 字段必须解锁
f.set(obj, "小红");                          // 修改值
Object value = f.get(obj);                   // 读取值
```

### 3.4 注意

- `getMethod` 只能拿 public；`getDeclaredMethod` 能拿本类私有，但调用前要 `setAccessible(true)`
- 反射有性能开销（比直接调用慢一个数量级），还会破坏封装（private 形同虚设），所以只在框架场景用
- 方法参数是"类型"：`getMethod("setAge", int.class)`

## 4. 注解是什么

**注解（Annotation）= 贴在代码上的"标签"，给程序看的元数据。** 它本身不干活，需要有人（反射或编译器）读取它才有意义。

**内置注解：**

```java
@Override               // 告诉编译器：这是重写，签名错了报错
@Deprecated             // 标记过时，使用处会警告
@SuppressWarnings("all") // 压制警告
```

## 5. 自定义注解

```java
import java.lang.annotation.ElementType;
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;
import java.lang.annotation.Target;

@Retention(RetentionPolicy.RUNTIME)   // 注解保留到运行期（反射能读到）
@Target(ElementType.METHOD)           // 这个注解只能贴方法上
public @interface MyTest {
    // 注解的"成员"是带默认值的无参方法
    String value() default "";

    int timeout() default 0;
}
```

**元注解（给注解的注解）：**

| 元注解 | 作用 |
| --- | --- |
| `@Retention` | 注解保留阶段：SOURCE（源码）/ CLASS（字节码）/ **RUNTIME（运行期，反射要用）** |
| `@Target` | 可以贴哪：TYPE / METHOD / FIELD / CONSTRUCTOR / PARAMETER |
| `@Documented` | 是否进 JavaDoc |
| `@Inherited` | 子类是否继承父类的注解 |

**使用：**

```java
public class MyTests {
    @MyTest(value = "case1", timeout = 100)
    public void testAdd() {
        // ...
    }

    @MyTest
    public void testSub() {
        // ...
    }
}
```

**关键：** 想让注解在运行期被反射读取，`@Retention` 必须是 `RUNTIME`。默认是 CLASS，反射读不到——这是最常见的坑。

## 6. 注解 + 反射：模拟一个测试框架（核心示例）

```java
// 扫描某个类的所有方法，找到带 @MyTest 的并执行
public class MyTestRunner {
    public static void run(Class<?> clazz) throws Exception {
        Object target = clazz.getConstructor().newInstance();   // 被测对象
        for (Method method : clazz.getDeclaredMethods()) {
            if (method.isAnnotationPresent(MyTest.class)) {     // 有 @MyTest 吗
                method.setAccessible(true);
                MyTest ann = method.getAnnotation(MyTest.class);
                System.out.println("执行测试：" + method.getName() + " " + ann.value());
                method.invoke(target);
            }
        }
    }
}
```

**这就是 JUnit 的原理**：JUnit 扫描你写的测试方法（带 @Test），自动创建对象、调用方法、统计通过/失败。
