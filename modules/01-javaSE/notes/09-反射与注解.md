## 核心要点

1. 反射：程序运行期动态获取并操作类的信息
2. 获取 `Class` 对象的三种方式
3. 反射创建对象、调用方法、访问字段
4. 自定义注解与元注解，`RUNTIME` 才能被反射读到
5. 注解 + 反射 = JUnit / Spring 的底层原理

## 1. 反射是什么

编译期写死调用：

```java
Student s = new Student();
s.study();
```

运行期按字符串动态调用（框架必须这么干，因为写框架时不知道你会定义什么类）：

```java
Class<?> clazz = Class.forName("lesson09.Student");
Object obj = clazz.getConstructor().newInstance();
clazz.getMethod("study").invoke(obj);
```

**框架 = 反射 + 注解。**

## 2. 获取 Class 的三种方式

```java
Class<Student> c1 = Student.class;               // 类名.class
Class<? extends Student> c2 = s.getClass();      // 对象.getClass()
Class<?> c3 = Class.forName("lesson09.Student"); // 全限定名（最灵活，最常用）
```

三种方式拿到的是**同一个** Class 对象（类只加载一次），`c1 == c3` 为 true。

## 3. 反射核心操作

```java
Class<?> clazz = Class.forName("lesson09.Student");

// 创建对象
Object o1 = clazz.getConstructor().newInstance();                       // 无参构造
Object o2 = clazz.getConstructor(String.class, int.class).newInstance("小明", 18);

// 调用方法
Method m = clazz.getMethod("study", String.class);   // public（含继承的）
m.invoke(o1, "数学");
Method pm = clazz.getDeclaredMethod("secret");       // 本类声明（含 private）
pm.setAccessible(true);                              // 解除 private 限制
pm.invoke(o1);

// 字段
Field f = clazz.getDeclaredField("name");
f.setAccessible(true);
f.set(o1, "小红");
Object value = f.get(o1);
```

- `getMethod` 只能拿 public；`getDeclaredMethod` 能拿本类私有，但需 `setAccessible(true)`
- 参数要写类型：`getMethod("setAge", int.class)`
- 反射有性能开销且破坏封装（private 形同虚设），只在框架场景使用

## 4. 注解基础

注解 = 贴在代码上的标签，本身不干活，需要反射或编译器读取才有意义。

```java
@Override  @Deprecated  @SuppressWarnings("all")
```

自定义注解：

```java
@Retention(RetentionPolicy.RUNTIME)   // 保留到运行期，反射才能读到
@Target(ElementType.METHOD)           // 只能贴在方法上
public @interface MyTest {
    String value() default "";        // 注解成员 = 带默认值的无参方法
    int timeout() default 0;
}
```

| 元注解 | 作用 |
| --- | --- |
| `@Retention` | SOURCE / CLASS（默认）/ **RUNTIME（反射必须）** |
| `@Target` | TYPE / METHOD / FIELD / CONSTRUCTOR / PARAMETER |
| `@Documented` | 是否进 JavaDoc |
| `@Inherited` | 子类是否继承父类的注解 |

**最常见的坑**：`@Retention` 默认是 CLASS，反射读不到，需要反射就必须写 RUNTIME。

## 5. 注解 + 反射：模拟测试框架

```java
public static void run(Class<?> clazz) throws Exception {
    Object target = clazz.getConstructor().newInstance();
    for (Method method : clazz.getDeclaredMethods()) {
        if (method.isAnnotationPresent(MyTest.class)) {   // 有 @MyTest 吗
            method.setAccessible(true);
            method.invoke(target);
        }
    }
}
```

这就是 JUnit 的原理：扫描带 `@Test` 的方法，自动创建对象、调用方法、统计通过/失败。
