## 1. 为什么需要集合

数组的长度是固定的，创建后不能变：

```java
int[] arr = new int[3];   // 想存第 4 个元素？不行
```

集合（Collection）是**长度可变**的容器，还能保证元素类型安全（配合泛型）、提供各种数据结构。日常开发中集合的使用频率远超数组。

## 2. 集合框架体系（先记这张图）

```text
Iterable
  └── Collection
        ├── List（有序、可重复）
        │     ├── ArrayList（数组实现，查询快）
        │     └── LinkedList（链表实现，增删快）
        └── Set（无序/有序、不可重复）
              ├── HashSet（哈希，最快）
              ├── LinkedHashSet（哈希+链表，保持插入顺序）
              └── TreeSet（红黑树，自动排序）

Map（键值对，key 不可重复）
  ├── HashMap（哈希，最快）
  ├── LinkedHashMap（保持插入顺序）
  └── TreeMap（按键排序）
```

| 接口 | 特点 | 常用实现 |
| --- | --- | --- |
| `List` | 有序、可重复、有下标 | ArrayList / LinkedList |
| `Set` | 不可重复 | HashSet / TreeSet |
| `Map` | 键值对，key 不可重复 | HashMap / TreeMap |

## 3. List：有序列表

### 3.1 ArrayList vs LinkedList（面试必考）

| 对比 | ArrayList | LinkedList |
| --- | --- | --- |
| 底层 | 动态数组 | 双向链表 |
| 随机访问（get） | O(1)，快 | O(n)，慢 |
| 中间插入/删除 | O(n)，需要挪元素 | O(1)，改指针 |
| 内存 | 连续紧凑 | 每个节点有额外指针开销 |
| 使用建议 | **绝大多数场景默认选它** | 大量头部/中间插入删除时才考虑 |

### 3.2 常用方法

```java
import java.util.ArrayList;
import java.util.List;

List<String> list = new ArrayList<>();
list.add("a");              // 追加
list.add(0, "x");           // 指定位置插入
list.get(0);                // 按下标取
list.set(0, "y");           // 修改
list.remove(0);             // 按下标删
list.remove("a");           // 按元素删（依赖 equals）
list.size();                // 长度（注意：不是 length！）
list.contains("a");         // 是否包含
list.indexOf("a");          // 首次出现下标，没有返回 -1
list.isEmpty();
```

### 3.3 遍历的四种方式

```java
// 1. 下标 for（可以改元素）
for (int i = 0; i < list.size(); i++) {
    System.out.println(list.get(i));
}

// 2. for-each（最简单，推荐）
for (String s : list) {
    System.out.println(s);
}

// 3. 迭代器（边遍历边删除时用）
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    String s = it.next();
    if (s.equals("a")) {
        it.remove();      // 用迭代器的 remove，安全
    }
}

// 4. forEach + Lambda（Java 8+，见下一课）
list.forEach(System.out::println);
```

**fail-fast（面试考点）：** for-each 遍历过程中直接 `list.remove()` 会抛 `ConcurrentModificationException`。因为迭代器会检查"修改次数"，发现被外部改了立刻报错，防止出现不可预知的行为。想边遍历边删，必须用 `iterator.remove()`。

## 4. Set：不可重复集合

**去重的原理（重点）：** 加入元素时先算 `hashCode` 找桶，再用 `equals` 比较；两者都相同就认为重复，拒绝加入。所以**自定义类放进 Set，必须重写 equals 和 hashCode**。

```java
import java.util.HashSet;
import java.util.LinkedHashSet;
import java.util.Set;
import java.util.TreeSet;

// HashSet：无序（哈希决定位置）、最快
Set<String> set1 = new HashSet<>();
set1.add("b");
set1.add("a");
set1.add("b");          // 重复，加不进去
System.out.println(set1);   // [a, b]（顺序不保证）

// LinkedHashSet：保持插入顺序
Set<String> set2 = new LinkedHashSet<>();
set2.add("b");
set2.add("a");
System.out.println(set2);   // [b, a]

// TreeSet：自动按自然顺序排序
Set<Integer> set3 = new TreeSet<>();
set3.add(5);
set3.add(1);
set3.add(3);
System.out.println(set3);   // [1, 3, 5]
```

**经典用途：** 去重（把 List 丢进 HashSet 再取出来）。

## 5. Map：键值对

### 5.1 常用方法

```java
import java.util.HashMap;
import java.util.Map;

Map<String, Integer> map = new HashMap<>();
map.put("语文", 90);          // 添加/更新
map.put("数学", 85);
map.get("语文");              // 90，key 不存在返回 null
map.getOrDefault("英语", 0);  // key 不存在返回默认值 0
map.containsKey("数学");      // true
map.remove("数学");
map.size();
```

### 5.2 遍历的三种方式（重点）

```java
// 1. keySet：先拿所有 key，再逐个 get（不推荐：多一次查找）
for (String key : map.keySet()) {
    System.out.println(key + " = " + map.get(key));
}

// 2. entrySet：同时拿 key 和 value（推荐）
for (Map.Entry<String, Integer> e : map.entrySet()) {
    System.out.println(e.getKey() + " = " + e.getValue());
}

// 3. forEach（Java 8+）
map.forEach((key, value) -> System.out.println(key + " = " + value));
```

### 5.3 HashMap 原理（面试必考，先理解大概）

- 底层是**数组 + 链表 + 红黑树**（Java 8+）
- `put(key, value)`：先算 `key.hashCode()` → 找到桶（数组下标）→ 桶里没有就放，有就 `equals` 比较
- 链表超过 8 个转红黑树，提升查找性能
- 扩容：元素达到 75%（负载因子）时数组翻倍，重新散列

**结论：HashMap 的性能和 hashCode 的质量强相关。** 自定义类做 key，必须正确重写 `equals` + `hashCode`（IDEA 可自动生成）。

## 6. Collections 工具类

```java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

List<Integer> nums = new ArrayList<>(List.of(5, 2, 8, 1, 3));
Collections.sort(nums);          // 升序：[1, 2, 3, 5, 8]
Collections.reverse(nums);       // 反转：[8, 5, 3, 2, 1]
Collections.shuffle(nums);       // 随机打乱
Collections.max(nums);           // 最大值
Collections.min(nums);           // 最小值
Collections.frequency(nums, 5);  // 元素出现次数
```

**自定义对象排序：** `Collections.sort(list)` 要求元素实现 `Comparable`（重写 `compareTo`），或者传一个 `Comparator`。Comparator 用 Lambda 写很简洁，下一课讲。

## 7. 集合常见坑（面试高频）

1. **集合不能放基本类型**：`List<int>` 编译错误，必须用包装类 `List<Integer>`
2. **contains / remove 依赖 equals**：自定义类没重写 equals，按地址比较，永远找不到"内容相同"的元素
3. **HashMap 的 key 要重写 equals + hashCode**：否则同样的内容被认为是不同 key
4. **边遍历边删**：for-each 里 remove 会抛 `ConcurrentModificationException`，用迭代器
5. **Arrays.asList 的坑**：`Arrays.asList(1,2,3)` 返回的 List 长度固定，不能 add/remove
