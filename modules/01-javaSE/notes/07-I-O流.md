# 07-I/O流

> 读笔记：约 40 分钟（练习另计）
> 配套练习：`modules/01-javaSE/exercises/lesson07/`（包名 `lesson07`）

## 核心要点

1. 字节流处理二进制（图片/视频），字符流处理文本，文本读写要指定编码
2. 四个抽象基类：InputStream / OutputStream（字节）、Reader / Writer（字符）
3. 按行读写用 BufferedReader.readLine() / BufferedWriter
4. 对象序列化：实现 `Serializable`，配合 ObjectOutputStream / ObjectInputStream
5. 日常文件操作优先用 NIO 的 `Files` 工具类

## 1. File 与流的选择

`File` 只是路径对象，**`new File` 不会创建真实文件**。

```java
File f = new File("data.txt");
f.exists(); f.isFile(); f.isDirectory(); f.length();
f.createNewFile(); f.mkdirs(); f.delete();
```

| 方向 | 字节流 | 字符流 |
| --- | --- | --- |
| 读 | InputStream | Reader |
| 写 | OutputStream | Writer |

| 对比 | 字节流 | 字符流 |
| --- | --- | --- |
| 单位 | 字节 | 字符（UTF-8 中文占 3 字节） |
| 适用 | 图片、视频、压缩包 | 文本文件 |
| 代表 | FileInputStream / FileOutputStream | FileReader / FileWriter |

口诀：**文本用字符流，二进制用字节流。**

## 2. 字节流复制文件

```java
try (BufferedInputStream in = new BufferedInputStream(new FileInputStream("a.jpg"));
     BufferedOutputStream out = new BufferedOutputStream(new FileOutputStream("b.jpg"))) {
    byte[] buffer = new byte[1024];
    int len;
    while ((len = in.read(buffer)) != -1) {
        out.write(buffer, 0, len);   // 只写实际读到的长度
    }
}
```

`read()` 返回 `-1` 表示读完；缓冲流内置 8KB 缓冲，比逐字节读写快得多。

## 3. 字符流读写文本

```java
// 按行读
try (BufferedReader reader = new BufferedReader(
        new InputStreamReader(new FileInputStream("data.txt"), StandardCharsets.UTF_8))) {
    String line;
    while ((line = reader.readLine()) != null) {   // null 表示读完
        System.out.println(line);
    }
}

// 按行写
try (BufferedWriter writer = new BufferedWriter(
        new OutputStreamWriter(new FileOutputStream("out.txt"), StandardCharsets.UTF_8))) {
    writer.write("第一行");
    writer.newLine();   // 换行，自动适配系统
}
```

**乱码根因**：`FileReader / FileWriter` 使用平台默认编码（Windows 是 GBK），读 UTF-8 文件必然乱码 → 改用上面的转换流显式指定 UTF-8。

**最简写法（Java 11+，日常首选）：**

```java
String content = Files.readString(Path.of("data.txt"), StandardCharsets.UTF_8);
Files.writeString(Path.of("out.txt"), content, StandardCharsets.UTF_8);
```

## 4. 对象序列化

```java
class Student implements Serializable {
    private static final long serialVersionUID = 1L;
    private String name;
    private transient String password;   // transient：不参与序列化（敏感字段）
}

// 序列化
try (ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("s.ser"))) {
    oos.writeObject(new Student());
}
// 反序列化
try (ObjectInputStream ois = new ObjectInputStream(new FileInputStream("s.ser"))) {
    Student s = (Student) ois.readObject();
}
```

未实现 `Serializable` 抛 `NotSerializableException`；`serialVersionUID` 不匹配抛 `InvalidClassException`。

## 5. NIO Files（现代推荐）

```java
Path p = Path.of("data.txt");
Files.exists(p); Files.size(p); Files.isDirectory(p);
Files.createFile(p); Files.createDirectories(Path.of("a/b/c"));
Files.readString(p); Files.writeString(p, "hello");
Files.copy(p, Path.of("c.txt"), StandardCopyOption.REPLACE_EXISTING);
Files.move(p, Path.of("n.txt"), StandardCopyOption.REPLACE_EXISTING);
Files.delete(p); Files.deleteIfExists(p);   // 后者不存在也不抛异常
```

递归遍历目录：

```java
try (var stream = Files.walk(Path.of("."))) {
    stream.filter(Files::isRegularFile).forEach(System.out::println);
}
```

## 6. 易错点

- 流必须用 try-with-resources，否则忘记 close
- 必须写 `out.write(buffer, 0, len)`，写成 `out.write(buffer)` 会把数组残留数据一起写入
- `read()` 返回 int（不是 byte），`-1` 是结束标志
- 缓冲流写入后要 flush；try-with-resources 关闭时会自动 flush
