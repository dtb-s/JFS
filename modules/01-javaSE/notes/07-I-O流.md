## 1. File 类（老 API，了解）

`File` 表示文件或目录的路径，注意：**new File 不会创建真实文件**，只是内存里的路径对象。

```java
import java.io.File;

File f = new File("data.txt");   // 相对路径（相对当前工作目录）
f.exists();                      // 是否存在
f.isFile();                      // 是否文件
f.isDirectory();                 // 是否目录
f.getName();                     // 文件名
f.getPath();                     // 路径
f.length();                      // 文件字节数

f.createNewFile();               // 创建空文件（受检异常）
f.mkdirs();                      // 创建多级目录
f.delete();                      // 删除
```

日常开发更推荐 NIO 的 `Files` 类（见第 6 节），功能更强、异常信息更友好。

## 2. 流的概念（重点）

**流（Stream）= 数据从一头流向另一头的通道。** 方向以**程序**为参照：

- 输入流：文件 → 程序（读）
- 输出流：程序 → 文件（写）

**四个抽象基类（记住这个对称结构）：**

| 方向 | 字节流 | 字符流 |
| --- | --- | --- |
| 读 | `InputStream` | `Reader` |
| 写 | `OutputStream` | `Writer` |

**字节流 vs 字符流：**

| 对比 | 字节流 | 字符流 |
| --- | --- | --- |
| 单位 | 字节（1 字节） | 字符（按编码，UTF-8 中文 3 字节） |
| 适用 | 图片、视频、压缩包等二进制 | 文本文件 |
| 代表 | FileInputStream / FileOutputStream | FileReader / FileWriter |
| 处理中文 | 不处理编码 | 按字符读，不乱码 |

**选择口诀：** 文本用字符流，二进制用字节流。

## 3. 字节流：复制文件

```java
// 基础版：一次读写一个字节（慢）
try (FileInputStream in = new FileInputStream("a.jpg");
     FileOutputStream out = new FileOutputStream("b.jpg")) {
    int b;
    while ((b = in.read()) != -1) {   // read() 返回 -1 表示读完了
        out.write(b);
    }
}
```

```java
// 改进版：缓冲区一次读一批（快得多）
try (FileInputStream in = new FileInputStream("a.jpg");
     FileOutputStream out = new FileOutputStream("b.jpg")) {
    byte[] buffer = new byte[1024];
    int len;
    while ((len = in.read(buffer)) != -1) {
        out.write(buffer, 0, len);    // 注意只写实际读到的长度
    }
}
```

**Buffered 包装（推荐）：** 缓冲流内置 8KB 缓冲区，性能更好：

```java
try (BufferedInputStream in = new BufferedInputStream(new FileInputStream("a.jpg"));
     BufferedOutputStream out = new BufferedOutputStream(new FileOutputStream("b.jpg"))) {
    byte[] buffer = new byte[1024];
    int len;
    while ((len = in.read(buffer)) != -1) {
        out.write(buffer, 0, len);
    }
}
```

## 4. 字符流：读写文本

**按行读（高频操作）：**

```java
try (BufferedReader reader = new BufferedReader(new FileReader("data.txt"))) {
    String line;
    while ((line = reader.readLine()) != null) {   // readLine 返回 null 表示读完
        System.out.println(line);
    }
}
```

**按行写：**

```java
try (BufferedWriter writer = new BufferedWriter(new FileWriter("out.txt"))) {
    writer.write("第一行");
    writer.newLine();        // 换行（自动适配系统）
    writer.write("第二行");
}
```

**乱码问题：** `FileReader` 用平台默认编码（Windows 上是 GBK）。跨平台要指定 UTF-8，用转换流或直接 `Files`：

```java
// 指定编码的字符流
try (BufferedReader reader = new BufferedReader(
        new InputStreamReader(new FileInputStream("data.txt"), StandardCharsets.UTF_8))) {
    // ...
}
```

**简单写法（Java 11+，日常最常用）：**

```java
String content = Files.readString(Path.of("data.txt"), StandardCharsets.UTF_8);
Files.writeString(Path.of("out.txt"), content, StandardCharsets.UTF_8);
```

## 5. 对象序列化

把**对象**直接存进文件（或网络传输），再读回来。

```java
import java.io.Serializable;

// 1. 类必须实现 Serializable（标记接口，没有方法）
class Student implements Serializable {
    private static final long serialVersionUID = 1L;  // 版本号，防止类改动后反序列化失败
    private String name;
    private int age;
    private transient String password;  // transient：不参与序列化（敏感字段）
    // 构造、getter/setter 省略
}
```

```java
// 2. 写入文件（序列化）
try (ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("student.ser"))) {
    oos.writeObject(new Student("小明", 18));
}

// 3. 读回对象（反序列化）
try (ObjectInputStream ois = new ObjectInputStream(new FileInputStream("student.ser"))) {
    Student s = (Student) ois.readObject();
    System.out.println(s.getName());
}
```

**注意：** 没有实现 `Serializable` 的类会抛 `NotSerializableException`；读回的类型和写入时不兼容会抛 `InvalidClassException`（serialVersionUID 不匹配）。

## 6. NIO Files 工具类（现代推荐）

Java 7 引入的 `java.nio.file.Files`，日常文件操作首选：

```java
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardCopyOption;

Path p = Path.of("data.txt");            // 路径对象

Files.exists(p);                         // 是否存在
Files.isDirectory(p);
Files.size(p);                           // 字节数
Files.createFile(p);                     // 创建文件
Files.createDirectories(Path.of("a/b/c"));  // 创建多级目录
Files.writeString(p, "hello");           // 写文本（Java 11+）
String s = Files.readString(p);          // 读文本（Java 11+）
Files.copy(p, Path.of("copy.txt"), StandardCopyOption.REPLACE_EXISTING);
Files.move(p, Path.of("new.txt"), StandardCopyOption.REPLACE_EXISTING);
Files.delete(p);                         // 删除
Files.deleteIfExists(p);                 // 存在才删，不抛异常
```

**递归列出目录：**

```java
try (var stream = Files.walk(Path.of("."))) {
    stream.filter(Files::isRegularFile)
          .forEach(System.out::println);
}
```
