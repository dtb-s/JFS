## 1. CS / BS 与网络基础

CS 需安装客户端（微信、游戏），BS 用浏览器访问（网站）。**Java 后端开发主要是 BS**。

- IP 地址：定位机器，本机是 `127.0.0.1`
- 端口：定位机器上的程序，0~65535（80 HTTP、443 HTTPS、8080 开发常用）

| 对比 | TCP | UDP |
| --- | --- | --- |
| 连接 | 三次握手，面向连接 | 无连接，直接发 |
| 可靠性 | 可靠、有序 | 可能丢包 |
| 速度 | 较慢 | 快 |
| 场景 | HTTP、文件传输、数据库 | 视频通话、游戏、DNS |

## 2. TCP Socket 编程

流程：服务端 `ServerSocket(port)` → `accept()` 等待连接；客户端 `Socket(ip, port)` 连接 → 双方读写 → close。

```java
// 服务端（一次服务一个客户端）
try (ServerSocket server = new ServerSocket(8888)) {
    Socket socket = server.accept();              // 阻塞，直到有客户端连接
    BufferedReader in = new BufferedReader(new InputStreamReader(socket.getInputStream()));
    PrintWriter out = new PrintWriter(socket.getOutputStream(), true);
    String line = in.readLine();                  // 阻塞，直到读到一行
    out.println("服务器收到：" + line);            // 回显
}

// 客户端
try (Socket socket = new Socket("127.0.0.1", 8888)) {
    PrintWriter out = new PrintWriter(socket.getOutputStream(), true);
    BufferedReader in = new BufferedReader(new InputStreamReader(socket.getInputStream()));
    out.println("hello");
    System.out.println("收到：" + in.readLine());
}
```

要点：`accept()`、`readLine()` 都是**阻塞**方法；通信走 `socket.getInputStream/OutputStream`；用完要 close（try-with-resources 自动关）。

多客户端：每个连接交给线程池处理。

```java
ExecutorService pool = Executors.newFixedThreadPool(4);
while (true) {
    Socket socket = server.accept();
    pool.execute(() -> handle(socket));
}
```

## 3. HTTP 协议（重点，阶段项目直接用）

HTTP 是**基于 TCP 的文本协议**。

```text
GET /index.html?name=zhang HTTP/1.1     ← 请求行：方法 路径 协议版本
Host: localhost:8080                    ← 请求头：字段名: 值
User-Agent: curl/8.0
                                        ← 空行（\r\n\r\n）表示请求头结束
请求体（GET 一般没有，POST 有）
```

```text
HTTP/1.1 200 OK                         ← 状态行：版本 状态码 原因短语
Content-Type: text/html                 ← 响应头
Content-Length: 13
                                        ← 空行
<h1>hello</h1>                          ← 响应体
```

解析要点：第一行按空格拆出方法 / 路径 / 版本；`?` 后面是查询参数；头字段固定为 `字段名: 值`；空行分隔头和体。

**常见状态码**

| 状态码 | 含义 |
| --- | --- |
| 200 | 成功 |
| 301 / 302 | 重定向 |
| 400 | 请求格式错误 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

**GET vs POST**

| 对比 | GET | POST |
| --- | --- | --- |
| 参数位置 | URL 上（`?name=xx`） | 请求体里 |
| 用途 | 查询 | 提交 / 修改数据 |
| 长度限制 | 受 URL 长度限制 | 无 |
| 安全性 | 参数会留在历史记录 | 相对好（非绝对安全） |

## 4. 手写 HTTP 服务器的思路

1. `ServerSocket` 监听端口
2. `accept()` 拿到连接
3. 读取请求文本，解析第一行的方法和路径
4. 按路径查找文件（如 index.html）
5. 拼响应：状态行 + 响应头 + 文件内容
6. 写回客户端并关闭连接
