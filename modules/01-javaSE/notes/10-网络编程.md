## 1. CS 与 BS 结构

| 结构 | 全称 | 例子 | 特点 |
| --- | --- | --- | --- |
| CS | Client/Server | 微信、游戏客户端 | 需要安装客户端，功能强 |
| BS | Browser/Server | 网站 | 浏览器访问，免安装，跨平台 |

**Java 后端开发主要是 BS**：浏览器发 HTTP 请求 → 服务器（Java 程序）处理 → 返回 HTTP 响应。

## 2. 网络基础

- **IP 地址**：定位一台机器。本机是 `127.0.0.1`（localhost）
- **端口**：定位机器上的一个程序，范围 0~65535。如 80（HTTP）、443（HTTPS）、8080（开发常用）
- **协议**：通信规则

**TCP vs UDP（面试必考）：**

| 对比 | TCP | UDP |
| --- | --- | --- |
| 连接 | 先建立连接（三次握手） | 无连接，直接发 |
| 可靠性 | 可靠（不丢包、有序） | 不可靠（可能丢） |
| 速度 | 慢一些 | 快 |
| 场景 | HTTP、文件传输、数据库 | 视频通话、游戏、DNS |

## 3. TCP Socket 编程（重点）

**通信流程：**

```text
服务器：ServerSocket(port) → accept() 等待客户端 → 读写 → close
客户端：Socket(ip, port) → 连接成功 → 读写 → close
```

### 服务器（一次只服务一个客户端）

```java
import java.io.*;
import java.net.*;

try (ServerSocket server = new ServerSocket(8888)) {
    System.out.println("服务器启动，等待连接...");
    Socket socket = server.accept();          // 阻塞，直到有客户端连接
    BufferedReader in = new BufferedReader(
            new InputStreamReader(socket.getInputStream()));
    PrintWriter out = new PrintWriter(socket.getOutputStream(), true);

    String line = in.readLine();
    System.out.println("收到：" + line);
    out.println("服务器收到：" + line);        // 回显

    socket.close();
}
```

### 客户端

```java
try (Socket socket = new Socket("127.0.0.1", 8888)) {
    PrintWriter out = new PrintWriter(socket.getOutputStream(), true);
    BufferedReader in = new BufferedReader(
            new InputStreamReader(socket.getInputStream()));

    out.println("hello");                     // 发送
    System.out.println("收到：" + in.readLine());  // 接收回显
}
```

**要点：**
- `accept()`、`readLine()` 都是**阻塞**方法，会等在那里
- 先 `server.accept()` 拿到连接，再通过 `socket.getInputStream/OutputStream` 通信
- 用完要 close；用 try-with-resources 自动关

### 多客户端（服务器要能同时服务很多人）

每来一个连接，开一个线程（或丢给线程池）处理：

```java
ExecutorService pool = Executors.newFixedThreadPool(4);
while (true) {
    Socket socket = server.accept();
    pool.execute(() -> handle(socket));   // 每个连接一个任务
}
```

## 4. HTTP 协议基础（重点，阶段项目直接用到）

HTTP 是**基于 TCP 的文本协议**，请求和响应都是特定格式的字符串。

### 4.1 请求格式

```text
请求行：方法 路径 协议版本
请求头：字段名: 值（多行）
空行：\r\n
请求体：GET 通常没有，POST 有
```

一个完整的 GET 请求（用浏览器/curl 访问 `http://localhost:8080/index.html?name=zhang`）：

```text
GET /index.html?name=zhang HTTP/1.1
Host: localhost:8080
User-Agent: curl/8.0
Accept: */*

```

**解析要点：**
- 第一行是请求行，用空格拆：方法 `GET`、路径 `/index.html`、协议 `HTTP/1.1`
- `?` 后面是查询参数：`name=zhang`
- 头字段格式固定：`字段名: 值`
- 空行（`\r\n\r\n`）表示请求头结束

### 4.2 响应格式

```text
状态行：协议版本 状态码 原因短语
响应头：多行
空行
响应体：HTML 等内容
```

一个简单响应：

```text
HTTP/1.1 200 OK
Content-Type: text/html
Content-Length: 13

<h1>hello</h1>
```

### 4.3 常见状态码（背下来）

| 状态码 | 含义 | 场景 |
| --- | --- | --- |
| 200 | 成功 | 请求处理成功 |
| 301/302 | 重定向 | 页面跳转 |
| 400 | 请求格式错误 | 客户端发错 |
| 404 | 资源不存在 | 路径写错 |
| 500 | 服务器内部错误 | 服务器代码 bug |

### 4.4 GET vs POST

| 对比 | GET | POST |
| --- | --- | --- |
| 参数位置 | URL 上（`?name=xx`） | 请求体里 |
| 用途 | 查询 | 提交/修改数据 |
| 长度限制 | 有（URL 长度） | 无 |
| 安全性 | 参数会出现在历史记录 | 相对好（不是绝对安全） |

## 5. 手写 HTTP 服务器的思路（阶段项目预告）

有了上面的知识，一个迷你 HTTP 服务器就是：

```text
1. ServerSocket 监听端口
2. accept() 拿到连接
3. 读取请求文本，解析第一行：方法 + 路径
4. 根据路径查找文件（如 index.html）
5. 拼响应：状态行 + 响应头 + 文件内容
6. 写回客户端，关闭连接
```

**这就是 `project/mini-http-server` 要做的事。** 本课练习 2 会先让你解析一个 HTTP 请求字符串，为它热身。

## 6. URL / HttpURLConnection（了解）

Java 程序自己发 HTTP 请求：

```java
URL url = new URL("http://localhost:8080/index.html");
HttpURLConnection conn = (HttpURLConnection) url.openConnection();
conn.setRequestMethod("GET");
int code = conn.getResponseCode();          // 200
BufferedReader in = new BufferedReader(new InputStreamReader(conn.getInputStream()));
String line;
while ((line = in.readLine()) != null) {
    System.out.println(line);
}
```
