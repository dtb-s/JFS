## 1. JDK、JRE、JVM 到底是什么

一句话：**JDK ⊃ JRE ⊃ JVM**。

| 名称 | 全称 | 包含什么 | 给谁用 |
| --- | --- | --- | --- |
| JDK | Java Development Kit | JRE + 开发工具（javac、java、jar 等） | 开发者 |
| JRE | Java Runtime Environment | JVM + 运行所需的类库 | 运行 Java 程序 |
| JVM | Java Virtual Machine | 执行字节码的"虚拟机" | 所有 Java 程序 |

**Java 为什么能"一次编写，到处运行"？**

1. 你写的是 `Hello.java`（源代码，人能看懂）
2. `javac` 把它编译成 `Hello.class`（字节码，人看不懂，但 JVM 能看懂）
3. 不同操作系统上有不同的 JVM，但所有 JVM 都认识同一套字节码
4. 所以编译一次，就能在 Windows / Linux / Mac 上运行

```text
Hello.java --javac--> Hello.class --java--> JVM 执行
```

## 2. 第一个程序

新建 `Hello.java`：

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

编译并运行：

```powershell
javac -encoding UTF-8 Hello.java
java Hello
```

输出：`Hello, Java!`

**必须记住的三件事：**

1. 类名（`Hello`）必须和文件名完全一致（包括大小写）
2. `main` 方法是程序入口，Java 从这里开始执行
3. 每个语句以分号 `;` 结尾

**代码解剖：**

| 代码 | 含义 |
| --- | --- |
| `public class Hello` | 定义一个公开的类，类名叫 Hello |
| `public static void main(String[] args)` | 主方法：程序入口 |
| `System.out.println(...)` | 打印一行文本 |
| `//` | 单行注释（`/* ... */` 是多行注释） |

## 3. 变量与基本数据类型

### 3.1 什么是变量

变量就是**内存中一块有名字的存储空间**，用来存放数据。

```java
int age = 25;          // 声明一个 int 变量，赋值为 25
double height = 1.75;  // 声明一个 double 变量
age = 26;              // 重新赋值
```

### 3.2 8 种基本数据类型（背下来）

| 类型 | 字节数 | 取值范围 | 默认值 | 示例 |
| --- | --- | --- | --- | --- |
| `byte` | 1 | -128 ~ 127 | 0 | `byte b = 100;` |
| `short` | 2 | -32768 ~ 32767 | 0 | `short s = 1000;` |
| `int` | 4 | 约 ±21 亿 | 0 | `int i = 100000;` |
| `long` | 8 | 很大 | 0L | `long l = 100L;` |
| `float` | 4 | 约 ±3.4e38 | 0.0f | `float f = 3.14f;` |
| `double` | 8 | 约 ±1.8e308 | 0.0 | `double d = 3.14;` |
| `char` | 2 | 0 ~ 65535 | '\u0000' | `char c = 'A';` |
| `boolean` | 逻辑上 1 | true / false | false | `boolean ok = true;` |

**易错点：**

- 整数默认是 `int`，超出 int 范围必须加 `L`：`long big = 3000000000L;`
- 小数默认是 `double`，要存进 `float` 必须加 `f`
- `String` 不是基本类型！它是类，后面课程会详细讲

### 3.3 命名规范

- 变量、方法：小驼峰 `myAge`、`userName`
- 类名：大驼峰 `HelloWorld`
- 常量：全大写 + 下划线 `MAX_COUNT`
- 不能以数字开头，不能用关键字（`class`、`int`、`if` 等），区分大小写

### 3.4 常量

用 `final` 修饰，赋值后不能再改：

```java
final double PI = 3.14159;
// PI = 3.0;  // 编译错误：无法为 final 变量赋值
```

### 3.5 类型转换

**自动转换（小 → 大）：** 从占字节少的类型转占字节多的类型，安全、自动发生。

```java
int i = 10;
double d = i;   // OK，int 自动转成 double
long l = i;     // OK
```

**强制转换（大 → 小）：** 可能丢失数据，需要显式写 `(类型)`。

```java
double d = 3.99;
int i = (int) d;   // i = 3，小数部分被直接砍掉（不是四舍五入！）
```

**经典陷阱 1：整数除法**

```java
double r = 9 / 5;      // 结果是 1.0，不是 1.8！因为 9/5 是整数除法
double r2 = 9.0 / 5;   // 结果是 1.8
```

**经典陷阱 2：字符串拼接**

```java
System.out.println("1 + 2 = " + 1 + 2);   // 输出：1 + 2 = 12
System.out.println(1 + 2 + " = 3");       // 输出：3 = 3
```

`+` 遇到字符串会变成拼接，而且从左往右算。

## 4. 运算符

### 4.1 算术运算符

| 运算符 | 含义 | 例子 | 结果 |
| --- | --- | --- | --- |
| `+` `-` `*` `/` | 加减乘除 | `7 / 2` | `3`（整数除法） |
| `%` | 取余 | `7 % 2` | `1` |
| `++` `--` | 自增自减 | `i++` | 见下 |

**自增自减是初学者第一道坎：**

```java
int i = 5;
int a = i++;   // a = 5，然后 i 变成 6（先取值，后自增）
int b = ++i;   // i 先变成 7，然后 b = 7（先自增，后取值）
```

记住：**`i++` 先用后加，`++i` 先加后用**。单独写 `i++;` 时两者没有区别。

### 4.2 复合赋值

```java
int x = 10;
x += 5;   // 等价于 x = x + 5，x 变成 15
x *= 2;   // 等价于 x = x * 2，x 变成 30
```

### 4.3 比较与逻辑运算符

```java
int age = 20;
boolean a = age > 18;        // true
boolean b = age >= 18;       // true
boolean c = age != 20;       // false

boolean r1 = (age > 18) && (age < 30);   // 与：两边都 true 才 true
boolean r2 = (age < 10) || (age > 60);   // 或：一边 true 就 true
boolean r3 = !r1;                        // 非：取反
```

**短路特性（面试常问）：**
`&&` 左边为 false 时，右边根本不执行；`||` 左边为 true 时，右边不执行。

```java
int n = 0;
boolean ok = (n > 0) && (10 / n > 1);   // 不报错：左边 false，右边没执行
```

### 4.4 三元运算符

```java
int score = 85;
String result = score >= 60 ? "及格" : "不及格";   // 结果是 "及格"
```

### 4.5 优先级（实用建议）

不用背全表，记住两条：

1. **括号最优先**，拿不准就加括号：`(a + b) * c`
2. 常见顺序：算术 → 比较 → 逻辑 → 赋值

```java
boolean r = 3 + 4 > 5 && 2 * 2 == 4;
// 等价于 (3 + 4) > 5 && (2 * 2) == 4，结果是 true
```

## 5. 流程控制

### 5.1 if / else

```java
int score = 85;
if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

注意：`if` 判断的是 boolean 值，`if (score = 85)` 是编译错误（赋值不是判断）。

### 5.2 switch

经典写法：

```java
int day = 3;
switch (day) {
    case 1:
        System.out.println("周一");
        break;   // 别忘了 break！否则会"穿透"继续执行下一个 case
    case 2:
        System.out.println("周二");
        break;
    default:
        System.out.println("其他");
}
```

新版箭头写法（Java 14+，不需要 break）：

```java
switch (day) {
    case 1 -> System.out.println("周一");
    case 2 -> System.out.println("周二");
    default -> System.out.println("其他");
}
```

### 5.3 for 循环

```java
// 打印 1 到 5
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

结构：`for (初始化; 条件; 步进) { 循环体 }`

**嵌套循环——打印 9x9 乘法表：**

```java
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print(j + "*" + i + "=" + (i * j) + "\t");
    }
    System.out.println();   // 换行
}
```

### 5.4 while / do-while

```java
// while：先判断，后执行（可能一次都不执行）
int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;
}

// do-while：先执行一次，再判断（至少执行一次）
int n = 10;
do {
    System.out.println(n);
    n++;
} while (n < 5);
```

### 5.5 break 和 continue

```java
for (int i = 1; i <= 10; i++) {
    if (i == 5) break;        // 遇到 5 直接结束整个循环
    System.out.println(i);    // 输出 1 2 3 4
}

for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;  // 跳过偶数，继续下一次循环
    System.out.println(i);     // 输出 1 3 5 7 9
}
```

## 6. 数组

### 6.1 创建数组

```java
// 方式一：先声明长度，用默认值填充（int 数组默认全是 0）
int[] scores = new int[5];

// 方式二：直接初始化（推荐）
int[] nums = {1, 2, 3, 4, 5};

// 方式三：声明 + new + 赋值
int[] nums2 = new int[]{1, 2, 3};
```

### 6.2 访问和遍历

```java
int[] nums = {10, 20, 30};
System.out.println(nums[0]);     // 10，索引从 0 开始
System.out.println(nums.length); // 3，length 是属性不是方法（没有括号！）

// 下标遍历
for (int i = 0; i < nums.length; i++) {
    System.out.println(nums[i]);
}

// for-each 遍历（更简单，但不能访问下标）
for (int n : nums) {
    System.out.println(n);
}
```

**最常见的数组错误：**

```java
int[] nums = {1, 2, 3};
System.out.println(nums[3]);   // 运行时错误：ArrayIndexOutOfBoundsException
// 合法索引范围是 0 ~ length-1
```

### 6.3 二维数组

```java
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6}
};
System.out.println(matrix[1][2]);      // 6
System.out.println(matrix.length);     // 2（有几行）
System.out.println(matrix[0].length);  // 3（第一行有几列）

for (int i = 0; i < matrix.length; i++) {
    for (int j = 0; j < matrix[i].length; j++) {
        System.out.print(matrix[i][j] + " ");
    }
    System.out.println();
}
```

### 6.4 Arrays 工具类

```java
import java.util.Arrays;

int[] a = {5, 2, 8, 1};
Arrays.sort(a);                    // 排序：{1, 2, 5, 8}
System.out.println(Arrays.toString(a));  // 直接打印 [1, 2, 5, 8]
int[] copy = Arrays.copyOf(a, a.length); // 复制一份
Arrays.fill(copy, 0);              // 全部填充 0
```

> 直接 `System.out.println(a)` 会打印出 `[I@1b6d3586` 这种"地址"，要用 `Arrays.toString`。

## 7. 用 AI 辅助这一课

学语法的阶段，AI 是**语法老师**，不是**代写工具**。正确用法：

**遇到编译错误，先自己读，再让 AI 解释：**

```text
我的代码：
（贴代码）
编译报错：cannot find symbol，位置在第三行。
请解释这个错误是什么意思，不要直接给我改好的代码。
```

**写完代码，让 AI 做 review：**

```text
这是我刚写的练习代码（贴代码）。
请指出：1）有没有 bug；2）哪些地方不符合规范；3）给 1～2 个改进建议。
不要直接重写整个程序。
```

**想验证自己的理解：**

```text
请给我出 5 道关于 Java 类型转换的判断题，我答完你再公布答案。
```

三条原则：

1. 先自己想 10 分钟，再问 AI
2. 让 AI"解释"而不是"代写"
3. 每个知识点至少要能手写一遍
