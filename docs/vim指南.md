# Vim 指南（终端文本编辑器速查）

> 适用场景：学习后期在 Linux 服务器上部署项目时，没有图形界面，改配置文件全靠终端编辑器。
> 学习目标：掌握 20 个高频操作即可满足日常使用，不要求背命令大全。

## 1. 为什么必须学 Vim

1. Vim 几乎预装在所有 Linux 发行版，服务器上必然有它
2. 部署阶段要改 Nginx 配置、环境变量、启动脚本，这些都在终端里完成
3. 学会 Vim 后，在任何服务器上都能直接编辑文件，不用来回下载上传
4. 在 IDEA 中可装 IdeaVim 插件练习，日常写代码也能顺便巩固

> 学习建议：先跑一遍 Linux 自带的 `vimtutor`（约 30 分钟），再配合本文速查表使用。

## 2. 核心概念：三种模式

Vim 与记事本最大的区别：**它有模式**。新手 90% 的困惑来自"不知道自己在哪个模式"。

| 模式 | 作用 | 如何进入 | 如何退出 |
|---|---|---|---|
| 普通模式（Normal） | 移动、删除、复制、查找（默认模式） | 打开文件即在此模式 | 按 `Esc` |
| 插入模式（Insert） | 输入文字 | 按 `i`、`a`、`o` 等 | 按 `Esc` |
| 可视模式（Visual） | 选中文本（类似鼠标拖选） | 按 `v`（字符）、`V`（整行）、`Ctrl+v`（块选） | 按 `Esc` |

```
普通模式 ──i/a/o──→ 插入模式
   ↑                  │
   └──── Esc ←────────┘
```

**记住一个原则：不输入文字时，永远停在普通模式。** 按几下 `Esc` 总是安全的。

## 3. 打开、保存、退出

| 操作 | 命令 | 说明 |
|---|---|---|
| 打开文件 | `vim 文件名` | 文件不存在则新建 |
| 保存 | `:w` | 写入磁盘 |
| 退出 | `:q` | 有未保存修改时会失败 |
| 保存并退出 | `:wq` 或 `:x` | 常用 |
| 强制退出不保存 | `:q!` | 放弃所有修改 |
| 保存并退出（快捷） | 普通模式按 `ZZ` | 大写 Z 按两下 |
| 打开另一个文件 | `:e 文件名` | 当前未保存会被阻止，先 `:w` |
| 查看帮助 | `:help` | 内置手册 |

> `:` 开头的命令叫 Ex 命令，在普通模式下输入，按回车执行。

## 4. 移动（普通模式）

| 按键 | 作用 |
|---|---|
| `h` `j` `k` `l` | 左 下 上 右（方向键也可用） |
| `w` `W` | 跳到下一个单词开头 |
| `b` `B` | 跳回上一个单词开头 |
| `0` / `$` | 跳到行首 / 行尾 |
| `gg` / `G` | 跳到文件第一行 / 最后一行 |
| `5G` | 跳到第 5 行 |
| `Ctrl+f` / `Ctrl+b` | 向下 / 向上翻一页 |
| `Ctrl+d` / `Ctrl+u` | 向下 / 向上翻半页 |
| `%` | 在成对括号 `( ) [ ] { }` 间跳转 |

**效率心法：移动用字母键，手不离开键盘主区，比方向键快。**

## 5. 编辑操作

**进入插入模式：**

| 按键 | 作用 |
|---|---|
| `i` | 在光标前插入 |
| `I` | 在行首插入 |
| `a` | 在光标后插入 |
| `A` | 在行尾追加（最常用） |
| `o` | 在下方新建一行并进入插入 |
| `O` | 在上方新建一行并进入插入 |

**删除、复制、粘贴（普通模式）：**

| 按键 | 作用 |
|---|---|
| `x` | 删除光标处字符 |
| `dd` | 删除整行（`3dd` 删 3 行） |
| `dw` | 删除一个单词 |
| `yy` | 复制整行（`3yy` 复制 3 行） |
| `yw` | 复制一个单词 |
| `p` / `P` | 粘贴到光标下方 / 上方 |
| `u` / `Ctrl+r` | 撤销 / 重做 |
| `r` | 替换光标处单个字符 |
| `.` | 重复上一次修改（神器） |

**删了后悔？** 立刻按 `u` 撤销；文件已经被保存也能撤销多次。

## 6. 可视模式：自由选取、复制、粘贴

**进入选区（三种）：**

| 按键 | 选区类型 |
|---|---|
| `v` | 字符级自由选取（像鼠标拖选） |
| `V` | 整行选取 |
| `Ctrl+v` | 块选（矩形区域，批量改列） |

**扩展选区：** 进入可视模式后，所有移动命令都变成"扩展选区"。

| 按键 | 作用 |
|---|---|
| `h j k l` / 方向键 | 逐字符、逐行扩展 |
| `w` `b` `e` | 按单词扩展 |
| `0` / `$` | 扩展到行首 / 行尾 |
| `gg` / `G` | 扩展到文件头 / 尾 |
| `/关键字` 回车 | 扩展到下一个匹配点 |
| `o` | **光标跳到选区另一端**（选过头了调头用，神器） |

**选中后的操作：**

| 按键 | 作用 |
|---|---|
| `y` | 复制（选区消失） |
| `d` / `x` | 剪切（删除并存入寄存器） |
| `c` | 剪切并进入插入模式（改写选中内容） |
| `p` | **用剪贴板内容替换选中部分**（可视模式下 p 不是粘贴） |
| `>` `<` | 整体缩进 / 反缩进（`V` 选多行后最常用） |
| `u` / `U` | 转小写 / 转大写 |
| `J` | 多行合并成一行（`V` 模式下） |

**粘贴（普通模式）：** `p` 粘到光标后/下方，`P` 粘到光标前/上方；被 `d` 剪切的内容同样可以 `p` 粘贴（剪切 + 粘贴 = 移动）。

**复制到系统剪贴板（Windows 常用）：**

| 按键 | 作用 |
|---|---|
| `"+y` | 复制到系统剪贴板（可粘贴到 Vim 外） |
| `"+p` | 从系统剪贴板粘贴 |
| `:set clipboard=unnamedplus` | 让 `y`/`p` 默认走系统剪贴板（可写进 ~/.vimrc） |

**文本对象：比拖光标更快的"定点选取"**

光标停在目标内任意位置，用 `v` + `i`(不含边界) / `a`(含边界) + 符号：

| 按键 | 选区 |
|---|---|
| `viw` | 一个单词 |
| `vi"` / `vi'` | 引号内内容 |
| `vi(` / `vi{` / `vi[` | 括号内内容 |
| `va(` | 括号连同内容一起 |
| `vap` | 一个段落 |
| `ggVG` | 全选 |

配合操作符使用：`ciw` = 改写当前单词、`di(` = 删除括号内内容、`yiw` = 复制当前单词。

> IDEA 装了 IdeaVim 插件后，以上全部通用。

## 7. 查找与替换

**查找：**

| 按键 | 作用 |
|---|---|
| `/关键字` | 向下查找，回车确认 |
| `?关键字` | 向上查找 |
| `n` / `N` | 下一个匹配 / 上一个匹配 |
| `:set hlsearch` | 打开搜索高亮（`set nohlsearch` 关闭） |
| `:nohlsearch` | 临时取消高亮 |

**替换（Ex 命令）：**

| 命令 | 作用 |
|---|---|
| `:s/old/new/` | 替换当前行第一个 old |
| `:s/old/new/g` | 替换当前行所有 old |
| `:%s/old/new/g` | 替换全文所有 old（最常用） |
| `:%s/old/new/gc` | 全文替换，逐个询问确认（改配置文件建议用这个） |

> 修改服务器配置文件前，先复制一份备份：`cp nginx.conf nginx.conf.bak`，再动 Vim。

## 8. 多文件与分屏

| 操作 | 命令 |
|---|---|
| 同时打开多个文件 | `vim a.java b.java`，`:n` 下一个，`:N` 上一个 |
| 水平分屏 | `:sp` |
| 垂直分屏 | `:vs` |
| 切换窗口 | `Ctrl+w` 再按 `w`（循环）或 `h`/`j`/`k`/`l`（按方向） |
| 关闭当前窗口 | `Ctrl+w` 再按 `q` |

分屏最实用的场景：一边看日志文件，一边改配置文件。

## 9. 常用配置（~/.vimrc）

把下面内容存到 `~/.vimrc`，体验立刻提升：

```vim
set number          " 显示行号
syntax on           " 语法高亮
set autoindent      " 自动缩进
set tabstop=4       " Tab 显示为 4 个空格宽
set shiftwidth=4    " 缩进宽度 4
set expandtab       " 按 Tab 输入空格（Java 项目通常约定 4 空格）
set hlsearch        " 搜索高亮
set ignorecase      " 搜索忽略大小写
set smartcase       " 但如果输入了大写字母，则区分大小写
```

> 改完立即生效：`:source ~/.vimrc`；或重启 Vim。

## 11. 怎么练

1. **先跑 `vimtutor`**：Linux 终端输入 `vimtutor`，官方交互教程，30 分钟过一遍
2. **日常强制使用**：改配置、写笔记都用 Vim，不用记事本/其他编辑器
3. **只记高频 20 个操作**：本文速查表里的就够用了，遇到不会的 `:help` 或问 AI
4. **验收标准**：能独立完成——打开 nginx.conf → 找到 server_name → 替换域名 → 保存退出
5. **进阶路线**（学完本指南后按需选）：宏录制 `q`、多文件搜索 `:grep`、插件（nerdtree、coc.nvim）

> Vim 的学习曲线陡峭但收益持久：一次学会，终身受用，所有 Linux 服务器通用。
